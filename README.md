**HanyuStar** is an interactive, mobile-optimized Progressive Web Application designed for Mandarin Chinese language learners. It offers comprehensive HSK vocabulary modules, character stroke order animations, radical breakdowns, speech synthesis, and an adaptive AI conversational teacher powered by LLM inference.

> *Note: For the multi-language production edition (supporting Spanish, French, German, Arabic, Japanese, and more with a FastAPI backend), see [Polyglot Language Coach](https://github.com/yasmenmad/polyglot-language-coach).*

---

## ✨ Features
- **HSK 1-3 Curriculum:** Curated vocabulary with Pinyin, audio pronunciation, and English translations.
- **AI Conversation Partner:** Real-time dialogue simulation with pronunciation guidance and grammar corrections.
- **PWA Mobile-First Layout:** Responsive, app-like navigation with smooth transitions.
- **Offline Flashcards & Quizzes:** Spaced review cards with streak tracking.

---

## 🛠️ Quickstart
1. Clone the repository:
   ```bash
   git clone https://github.com/yasmenmad/HanyuStar.git
   cd HanyuStar
   ```
2. Configure your API key:
   - Copy `config.example.js` to `config.js`
   - Add your Groq API key (from [console.groq.com](https://console.groq.com))
3. Open `index.html` in any web browser.
